BMTC Bengaluru Bus Reports — demo prototype

Files
- index.html: dashboard, demo sign-in/sign-up and BMTC report form
- style.css: dashboard and form styling
- script.js: page navigation, demo authentication and local report storage

Run
1. Keep all three files in the same folder.
2. Open the folder in VS Code.
3. Run index.html with Live Server.
4. Use “Open dashboard demo”, then “Submit a Report”.

Important
This is a frontend demo only. Reports are stored in this browser's localStorage and are not sent to BMTC. Dashboard charts and example rows are illustrative, not verified BMTC statistics or live bus tracking. Demo authentication is not secure and should not be used for real accounts. For production, connect a secure backend and an authorized BMTC reporting/API integration.
